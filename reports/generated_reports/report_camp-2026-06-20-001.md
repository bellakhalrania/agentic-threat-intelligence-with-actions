## Recommendations  

1. **Containment**  
   * Isolate **WORKSTATION‑07** from the network until a full forensic analysis is complete.  
   * Block outbound traffic to **185.44.12.7** and any other known malicious IPs.  

2. **Detection & Monitoring**  
   * Deploy PowerShell logging (module `PowerShell Script Block Logging`) and enable `Get-Content` monitoring.  
   * Alert on new scheduled tasks and encoded PowerShell commands.  
   * Correlate outbound traffic with known malicious IPs in real time.  

3. **Mitigation**  
   * Enforce code‑signing for all PowerShell scripts.  
   * Restrict PowerShell execution to signed scripts only (`Set-ExecutionPolicy AllSigned`).  
   * Harden scheduled‑task creation: require administrative approval and audit all task changes.  
   * Apply network segmentation and micro‑segmentation to limit SMB lateral movement.  

4. **Remediation**  
   * Conduct a full endpoint scan with up‑to‑date AV/EDR.  
   * Reset credentials for all accounts that accessed the compromised workstation.  
   * Review and patch any vulnerabilities that could be exploited for initial access.  

5. **Future Prevention**  
   * Implement a Zero‑Trust model for privileged accounts.  
   * Deploy a next‑generation firewall with deep packet inspection for outbound C2 traffic.  
   * Regularly update threat intelligence feeds and integrate them into SIEM/SOAR workflows.
